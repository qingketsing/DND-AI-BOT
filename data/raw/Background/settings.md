# 城市

# 死寂的世界

天空是冰冷而洁白的，笼罩着无尽的混凝土，它们高耸而广阔。野兽派的建筑以奇异的角度刺入永不褪色的天空。

人造的、单色的荒原一直延伸到地平线。它甚至超越了地平线。在这世上再无他物——没有自然的，没有生命的。

只有城市。

# 空旷的大厅

城市是黑、灰、白色的。它由混凝土、金属和玻璃构成。

它的形态棱角分明，几何感十足，常常构成更大的重复性结构。曲线之处，则宏伟而舒展。

图案变化万千，独一无二。无论你 venturing 多远，你都不会看到相同的建筑两次。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-04-07/34973620-4e07-463e-bc62-1e9f7c860651/86d9d0b65d0f7f57ae458e84e7a7a91549742ee8a3470ad4fc6b043439af8576.jpg)

城市由大厅、走廊和广场组成。

有些大厅似乎曾有过某种用途——住宅、集会场所、神庙——

但大多数都只是空旷的。

那些并非如此的，常常显得像是其

辨识特征被小心翼翼地

剥离了。几乎没有损坏的痕迹，而且

总是整洁的，但仔细观察时，曾经存在之物的缺失感却能强烈地感受到。

虽然单个建筑相互交错，但平均而言，城市

的表面保持着一个大致

恒定的水平，只有在长距离上才会缓慢变化。

唯一的例外是裂隙——建筑流之间深邃、巨大的坑洞。有些

只深达数百或数千英尺，

底部是屋顶和广场。有些则深不见底，只能看到

黑暗。

无论你向下深入多远，都没有

所谓的地面——只有更深的

大厅、更深的房间、

更深的走廊。

只有城市。

有些地方有雕像或雕塑。它们可能排列在宏伟走廊的两侧，或作为广场的中心装饰。它们几乎总是抽象的，如同周围的建筑一样神秘莫测。

有些地方有机械。管道穿过混凝土，电线横跨建筑或裂隙，装置静静地躺在空荡荡的大厅里。它们的用途很少容易被辨别。

无论它们曾是做什么用的，现在都已不再运转。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-04-07/34973620-4e07-463e-bc62-1e9f7c860651/7ec367f343893f943e16bf016db0b03b504eb4ac8d63fed03fed91e20d310c87.jpg)

有些地方有似乎曾经是灯具的东西——球体、立方体或条状的浑浊白玻璃，嵌入墙壁或悬挂在金属支架上。

它们已不再工作。城市内部变得黑暗，尤其是在下方。

有连接不同楼层的楼梯。有时它们宽阔而宏伟，由混凝土凿成；有时它们细小、蜿蜒如螺旋楼梯；有时它们是悬挂在建筑外部的金属栏杆或梯子。

大多数楼梯似乎是为类人生物设计的，但有些台阶对类人生物来说太大了，仿佛是为巨人建造的。

同样，大多数门都是类人生物的尺寸，但偶尔也能发现巨大的入口。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-04-07/34973620-4e07-463e-bc62-1e9f7c860651/859329bc21c598cae3cb15144efaa44a19998ac991cfd48e3f35c795bf68d0db.jpg)

城市几乎没有损坏。

虽然灰尘和污垢会缓慢地积聚在它的表面，但与更有人居住的世界相比，积聚的量微乎其微。

混凝土常常有污渍，金属常常略有锈蚀，但风化作用也非常轻微。很少有裂缝，很少有破碎或缺失的建筑构件，很少有城市被遗弃这么久迹象。

没有雨水池，因为城市里不下雨。

没有苔藓、地衣或藤蔓填满裂缝。

没有生命。

没有骨头。

没有尸体。

# 但并非完全死寂……

进入城市的旅者可能会原谅自己最初认为在这片空虚的世界里独自一人，但敏锐的人很快就会注意到活动最细微、最微妙的迹象。

深处的隆隆声，通过无尽的建筑回荡，如同微小的、细微的震动。

下方黑暗中有什么东西在移动。

# 凝固的天空

太阳静止地悬挂在城市上空，处于永久的上午状态。按理说，这意味着地球的另一边应该是夜晚，但这从未被观察到——无论你在哪里，一天的时间都保持不变。

城市有两个月亮——一个比另一个大，但都不如太阳看起来那么大——它们尽管如此，仍在永恒阳光普照的天空中遵循着正常的轨迹。

# 通往城市的门

虽然其他类型的裂隙可能以任何方式出现，但滑门（slip doors）在这个世界几乎总是作为城市建筑的一部分出现：

- 一扇嵌入墙壁的金属门，前一刻通往另一个世界，但当你移开视线后，只通往一条走廊。
- 一扇沉重的混凝土门，关闭时，其接缝会消失，与墙壁齐平。
- 广场中央一个棱角分明的拱门——前一刻是传送门，下一刻只是一个雕塑。

# 地下的世界

当你沿着城市的层层深入时，起初几乎没有什么变化。

阳光会找到通往这里的方法，无论是通过裂隙的窗户，还是通过上方大厅的反射。

建筑风格相似，但不完全相同——可定义用途的房间更少，取而代之的是更多的大型开放式大厅和迷宫般的走廊。有时门会通往裂隙底部的广场，或其墙壁上的阳台。

墙壁里有更多锁着的或隐藏的门，通往金属服务走廊的网络，这些走廊在房间之间和周围穿梭，不为人所见。

# 暮光大厅

当你进一步深入时，光线逐渐消退；太远无法反射，开口太少，而且现在大多数都被裂隙的墙壁遮挡了。在这里，旅者可能会开始发现他们并非孤身一人的证据。

迹象仍然稀少且难以寻觅，但并非不可能找到。营地的残余——古老，但明显比城市年轻得多；墙壁上刻划的涂鸦——箭头、指示、留言，“Suzie woz here”；一本被遗弃的皮面日记；一根孤零零的人类股骨。

有时金属服务走廊会通往封闭的混凝土隧道，高约几米，宽也差不多，其长度方向有深槽，与隧道的中心等距。这些隧道有时会分成两股，但从不以死胡同结束。当它们上下连接楼层时，它们会平滑地进行，而不是分级。

就像地表城市那种显而易见的空虚感一样，这里也有一种东西被移除的感觉。

# 车站

在更深的暮光区域，建筑又增加了一个元素：车站。这些高耸入云、如同大教堂般的房间，墙壁图案错综复杂，装饰风格为装饰艺术（art-deco），尽管是灰度色调，却与城市其他部分的实用混凝土形成了鲜明对比。

每个车站的中间都有一条隧道穿过，使得车站的地板下降约两米，形成一个平台。在这个落差的底部，以及继续延伸到房间两端的隧道入口处，是一对粗大的金属轨道。

通常巨大的玻璃和铬制吊灯悬挂在尖顶天花板的中央；有时——与城市大多数灯具不同——这些灯会亮起，将房间笼罩在柔和、病态的蓝绿色光芒中。

它们的控制装置找不到——当火车靠近时，它们就会亮起。

# 火车

# 古老的巨兽

城市中几乎所有的机械都已完全失效，在它静止了数千年的岁月中，已经磨损或锈蚀殆尽。唯一的例外是火车。

火车是如何逃过损坏和腐蚀的，这一点不得而知，但总的来说，关于火车人们知之甚少。它们由什么驱动，如何在城市中规划路线，它们又如何知道它们所知道的事情，这些都不得而知。

唯一已知的是，当有人需要时，火车就会找到他们。

# 轨道

火车使用的轨道以复杂的模式在城市中蜿蜒向上、向下、向内、向外。通过网络的开口，有时可以看到它们在黑暗中闪烁的外部灯光。

轨道会上下连接楼层，但从不延伸到暮光区域之外；它们的隧道延伸到那里，轨道似乎已被移除。

这个网络密集而错综复杂——凡人极难导航——但火车总能找到最快的路线到达目的地。

# 迷失与需要帮助者

当有人靠近车站并需要帮助时——迷路、受伤、逃避袭击者、离目的地遥远且食物耗尽，无论是什么原因——火车就会找到他们。它会在最近的车站停下，打开车门——巨大的、向上铰链的舱门——然后等待。一旦有人上车，车门就会关闭，它会将他们载往任何需要去的地方，或者至少是最近的车站。

它们会为任何人这样做，而且它们似乎不遵循任何道德框架；它们可能会像运送难民寻求帮助一样，将一支战争队伍运送到你家门口。

火车唯一不允许的是在车上发生暴力行为。城市中幸存的社会已经为此付出了惨痛的代价。

火车很少会重复相同的路线，除非是在帮助旅客时才会停下。当它们不服务于凡人时，它们只是在轨道网络中轰鸣，似乎是随机的。许多人曾试图预测火车的运动，但都失败了。

# 无光之厅

当你远离光源时，城市的几何结构变得越来越抽象，越来越难以穿越，地板以奇怪而陌生的角度倾斜。最终，你会开始发现城市停止的地方。一层地板悬空于无尽的黑暗深渊之上。

如果你走得足够远，最终会发现它继续向下延伸的地方；巨大的混凝土柱子，或由大厅、楼梯和火车隧道形成的巨型墙壁和柱子。沿着这些向下下降数百层，你会发现它们的底部再次与城市景观相遇；巨大的、高耸的洞穴的地面。

# 之下

这个城市与上面的城市不同。

这里没有雕像、机器或走廊；只有巨大的混凝土板，它们相互挤压，就像地表的建筑一样。

有些是空心的，但它们的内部似乎不是房间。有些侧面有孔洞，但它们不是窗户，只是奇怪的几何形状，以奇特、多变的布局出现。没有楼梯，所以类人生物无法在没有找到攀爬或穿过它们的方法的情况下穿越这些板。

这些板之间没有缝隙，形成了一个无缝的地面。当出现裂隙时——非常罕见——它们是深达数英里、望不到底的巨大鸿沟。

直射阳光无法到达这么深的地方，但它通过上方楼层的反射，提供了一丝微弱的环境光，使其比漆黑略好一点。

空气中有一种淡淡的咸湿味，这与上方世界压抑的干燥形成了对比。

这里勉强可以维持生命，尽管数量有限。苔藓在裂缝中生长，蘑菇从墙壁上冒出来，有时可以看到老鼠在四处奔窜。

这里也有人。

# 无光之生

他们最初来自其他世界。他们的故事各不相同——有些人被困在这里，有些人为了逃离旧世界的苦难而来，有些人路过并不知何故觉得这里像家。

城镇围绕着光源和热源而兴起，因为在黑暗中生存非常艰难。这个热源可能是一件罕见的、仍在运作的城市科技设备，一个嵌入地下的巨大磷光球体灯；它可能是一个永久性的现实裂隙，通往一个温暖阳光的世界；它可能是一个由镇民们一丝不苟地维护的神秘仪式。没有两个定居点是相同的。

这里还有其他生物；栖息在桥墩台阶里的龙，在甜美的黑暗中消磨时光的吸血鬼部落，在柱厅里打盹的洞穴巨魔。

然而，这一切都来自其他世界。城市本身没有生命留存下来。

# 被遗忘之海

如果你深入无光之厅的裂隙，找到某种方法下降数英里越来越垂直的栈道和悬崖，你会发现空气变得越来越湿润和咸，岩石会因为现在附着在其上的海藻而变得越来越滑，海浪拍打岩石的声音会从下方回响上来，直到最终裂隙下降到一个黑色而咸涩的海洋，尽管没有风，它却剧烈地翻腾和拍打。

很难知道城市还会向下延伸多远；也许它会永远延续下去。被遗忘之海的汹涌洋流会卷走任何进入的人——将他们拖入深渊淹死，或将他们撞碎在岩石上——因此，关于这一点之外是什么的知识很难获得。

有些人到达了这里并幸存下来——这本身就是一项罕见而英勇的壮举——声称他们看到了深处移动的光芒。

# 无光社会

城市无光区域的社会形态极其多样。它们围绕的能源来源、社会结构、居住的文化和物种，以及它们来自的世界——所有这些都差异巨大。

此表格允许你轻松地生成一个要遭遇的社会，但这远非无光之厅中可能遇到的所有情况；鼓励你用最适合你故事的社会来填充你游戏中的城市版本。

# 游牧社群

比定居点更罕见的是游牧社群。由于定居点以外的地区普遍无法生存，这些游牧民族几乎总是商人或劫掠者，通过各自的方式以定居点的资源为生。

# d6 游牧民族

1. 在城市中游荡寻找猎物的吸血鬼部落。
2. 在定居点之间穿梭，买卖各社会独特商品的兽人商队。
3. 喜欢偷窃任何他们看上的东西的哥布林部落，他们没有私有财产的概念，但本质上是非暴力的。
4. 在城市中漫无目的地游荡的神秘妖精剧团。
5. 维京风格人类的劫掠队，拥有从他人那里偷来的零散技术，他们骑着驯化的恐龙并挥舞着突击步枪。
6. 一位发誓和平的恶魔领主，现在利用他的恶魔仆从和随从保护一支商队在定居点之间旅行。
