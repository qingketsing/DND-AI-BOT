# HTTP MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal HTTP backend that can create sessions, fetch sessions, and send messages with a mock reply.

**Architecture:** Keep HTTP concerns in handlers, session flow orchestration in a service, and persistence in the existing in-memory repository. DTOs isolate transport JSON from the domain model so the API can evolve without leaking internal types.

**Tech Stack:** Go, net/http, in-memory repository, standard testing package
